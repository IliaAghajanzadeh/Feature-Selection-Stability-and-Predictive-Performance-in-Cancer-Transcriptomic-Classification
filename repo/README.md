# Feature Selection Stability in Cancer Transcriptomic Classification

Code and results for a controlled study of NSGA-II gene-panel reproducibility
on cancer transcriptomic data (ICBME 2026 submission).

## What this repo answers

Does a gene panel selected by NSGA-II stay the same across independent runs,
or only its *accuracy* does? We test this on Leukemia and Colon microarray
data, against a random-search baseline (same budget) and an mRMR filter
baseline (matched panel size).

## Repo map — what's where and why

| Folder | Contents | Why it matters |
|---|---|---|
| `src/` | Core algorithm: bootstrap sampling, GA (NSGA-II), nested CV, stability metric (Φ) | This is the actual method. Read `ga.py` + `stability.py` first. |
| `scripts/` | One script per experiment (random-search control, mRMR control, OOB eval, disjoint-panel test, figure generation) | Each script reads from `results/*.json` or regenerates it. Names match paper section numbers where possible. |
| `results/` | Every number in the paper, as raw JSON | **This is the ground truth.** If a number in the paper looks wrong, check here first — not the manuscript. |
| `figures/` | Final PNG + PDF figures used in the paper | Regenerated by `scripts/figures.py` and `scripts/figures_baselines.py`. |
| `manuscript/` | `paper.tex` and compiled `paper_IEEE.pdf` | The paper itself. |
| `notebooks/` | Original exploratory Jupyter notebooks | Messier than `src/` — kept for transparency, not for reuse. If `src/` and a notebook disagree, trust `src/`. |
| `data/` | **Not included** — see below | Colon and Leukemia matrices are third-party (see Data section). |

## Setup

```bash
pip install -r requirements.txt
```

Data files (`colon.mat`, `leukemia.mat`) are NOT included in this repo — see
`data/README.md` for where to get them and where to place them.

## Reproducing a result

```bash
# main NSGA-II runs
python src/run_main.py

# baselines
python scripts/run_colon.py          # random search, colon
python scripts/run_bc_matched.py     # matched control, breast cancer
python scripts/run_matched.py        # matched seed control

# figures
python scripts/figures.py
python scripts/figures_baselines.py
```

## Environment notes

Some result files record the exact package versions used (see the `env` key
inside `phase1_random_search.json`, `phase2_mrmr.json`, and
`phase1_nsga_verification.json`); the original main-run files predate that
logging convention. If you re-run anything, pin versions with
`requirements.txt` and re-verify against `results/instrumentation.json` for
the evaluation-budget counts.
